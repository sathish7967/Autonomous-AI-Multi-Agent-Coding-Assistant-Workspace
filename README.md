# 🤖 Autonomous AI Multi-Agent Coding Assistant Workspace

An asynchronous, stateful multi-agent orchestrator panel built to automate software engineering features. The application utilizes a highly constrained, zero-temperature model pipeline to coordinate three distinct corporate roles—Software Architect, Systems Engineer, and Automated Integration QA Tester—delivering verified, audited code architectures directly to an interactive developer dashboard terminal.

---

## 🚀 MNC Architecture Signal (What This Proves)
* **Autonomous Stateful Orchestration**: Demonstrates the practical implementation of agentic AI principles, configuring independent language models to pass structured context downstream without logic leakage or state degradation.
* **Deterministic Code Processing**: Utilizes deterministic parameter tuning (`temperature=0.0`) and specialized line indexing to enforce structured outputs, bypassing common text generation and formatting parsing faults.
* **Automated Peer-Review Loop**: Implements automated linting and continuous vulnerability reviews directly within the AI cycle, capturing deep structural edge case flaws prior to code execution.

---

## 🛠️ Core Technology Stack & Architecture Components
* **Backend Core Runtime Engine**: FastAPI (Python 3.11+)
* **Asynchronous Server Wrapper**: Uvicorn ASGI Runner
* **Agent Integration Framework**: LangChain Expressions Core (LCEL)
* **Cloud Core Infrastructure**: Groq API Cloud Networking Engine
* **Flagship Open Model Instance**: `llama-3.1-8b-instant` (High-Throughput Model Block)
* **Frontend Developer Terminal UI**: HTML5 Canvas Styles, Asynchronous JavaScript Fetch Pipelines

## 📊 Complete System Multi-Agent Workflow Mesh

```text
[User Feature Requirement] ──> [Node Alpha: Planner] ──> Logic Blueprints ──> [Node Beta: Developer] ──> Python Code ──> [Node Gamma: QA Tester] ──> Inbound Log Stream Panel
```

1. **Requirement Analysis**: The user types a technical code feature requirement into the command console.
2. **Node Alpha (Architectural Planner)**: Deconstructs the user prompt constraints, map dependencies, and compiles a Markdown logic roadmap.
3. **Node Beta (Senior Development Compiler)**: Consumes the logical blueprint, handles edge conditions, and structures a raw Python source code block.
4. **Node Gamma (Automated QA Integrator)**: Reviews the source code block against memory leaks, syntax errors, and algorithmic complexity limits, appending an upper-case assertion verdict (`PASSED` or `FIX_REQUIRED`) onto the stream log header.

## 💻 Technical Setup & Local Execution Routine

### 1. Start the Asynchronous Agent Mesh Server Instance
Open your dedicated terminal pane workspace inside VS Code and spin up your backend wrapper on port `8001`:
```bash
cd project2_agent
uvicorn app_agent:app --host 127.0.0.1 --port 8001 --reload
```
*Verify that your console log prints: `Application startup complete` on port 8001.*

### 2. Launch the Developer Interactive Workspace Dashboard
Right-click your local **`index_agent.html`** file and launch it using VS Code's **Live Server** extension (or execute via `http://127.0.0`).
